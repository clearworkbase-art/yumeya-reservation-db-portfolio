# テスト計画／確認済み範囲

## 自動テスト候補
- 本日より前の日付はNG
- チェックアウトが同日・前日ならNG
- 宿泊日数が14泊を超えるならNG
- 受け付ける客室はMATSU/TAKE/UMEのみ
- 人数は1〜4人
- 実在しない日付はNG
- 空欄と不正入力はNG

`src/test/java/.../ReservationRulesTest.java` は依存フレームワークのないJavaのテスト用mainです。`mvn test` だけで自動実行する構成ではなく、直接mainメソッドを実行してください。

## 設計上の制約
本デモはセッション保持のみなので、ブラウザのセッション終了やTomcat再起動で情報を失う可能性があります。データベースによる持続性、二重予約防止、同時アクセス、認証認可、メール、決済を実装するまで、実運用に使用しないでください。
