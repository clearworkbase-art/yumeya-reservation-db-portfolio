# 次の候補：あけぼの保育園「園見学申込デモ」

旅館の入力・確認・完了を動作検証してから着手。既存保育園サイトにある `u_contact/index.html` は現在HTMLフォームのみで送信処理がないため、これを置換せず別導線 `visit` を作るのがおすすめ。

- 園見学希望日・時間帯・参加人数を選択
- 入力チェック → 確認 → デモ完了
- 管理画面の表示・承認機能やデータベースは学習進捗に合わせて追加
- 実際の園児・保護者の氏名、電話番号、メールは使用しない
- まずは架空データだけで進める

旅館とほぼ同じデモを2つ量産するより、保育園では「時間帯ごとの定員」「重複応募」「申込状況変更」など後で別の技術課題を見せられる設計にすると効果的。DB/DAO/JDBCを習得するまで実予約・永続保存は実装しない。
